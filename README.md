【猫之琴】
适用于原神、蛋仔派对、元梦之星、永劫无间、逆水寒、摩尔庄园、第五人格等游戏
只要有21琴键都可以自动弹奏
就像音乐播放器一样，自动弹奏谱子（midi，txt）
可以控制速度，单曲循环，列表循环模式



快捷键：
双击播放
上下箭头切歌
左右箭头调速
空格播放/暂停
上方数字键切模式： 0=完整弹奏，1=只留最高音，2=跳过背景音弹奏



特色【PC、手机，点赞】三模式
-PC模式：电脑上的游戏/模拟器等
选择游戏进程，双击谱子播放，鼠标点击游戏焦点，会自动弹奏，离开游戏焦点会停止弹奏



\-安卓手机弹奏模式：需要电脑和手机在同一个wifi网络中。
点击【ADB模式-就绪】弹出辅助面板。
手机设置进入开发者模式，进入无线调试里面，扫码自动连接adb无线调试（可以问豆包）
连接成功后，手机打开游戏进行弹奏：双击谱子播放，电脑自动下发命令点击手机屏幕弹奏。
如果这时需要手机控制，就安装GMAUT.apk，授予悬浮窗权限，进游戏，可以控制电脑弹奏



\-安卓手机点赞模式：需要电脑和手机在同一个wifi网络中。
点击【ADB模式-就绪】弹出辅助面板。
手机设置进入开发者模式，进入无线调试里面，扫码自动连接adb无线调试
连接成功后，手机打开抖音看直播，可以在竖屏状态下，自动发送点屏幕命令点赞，30分钟大概6000赞
